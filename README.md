# Sistema de Gestión de Reservas - Frontend

Interfaz de usuario moderna y dinámica construida con **React** para la gestión operativa de hoteles.

## 🚀 Tecnologías Utilizadas

- **Framework:** [React 19](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Iconos:** [Lucide React](https://lucide.dev/)
- **Gestión de Fechas:** [date-fns](https://date-fns.org/)
- **Tipado:** TypeScript

## 💡 Funcionalidades Destacadas

- **Calendario Interactivo:** Visualización fluida de la disponibilidad y gestión de reservas en tiempo real.
- **Dashboards Operativos:** Paneles de control para administración, ingresos e informes de comisiones.
- **Gestión de Recursos Humanos:** Módulos completos para empleados, roles y permisos.
- **Control de Gastos:** Interfaz intuitiva para el seguimiento financiero de la operación.
- **Diseño Responsivo:** Adaptado para su uso en distintos dispositivos.

## 🛠️ Instalación y Configuración

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/manucastroa7/sistemaReservas-front.git
   cd sistemaReservas-front
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Variables de Entorno:**
   Configura la URL de la API en tu archivo `.env`:
   ```env
   VITE_API_URL=http://localhost:3000
   ```

4. **Ejecutar en desarrollo:**
   ```bash
   npm run dev
   ```
